# Inventory Tracker | C# Windows Forms

## Overview
A C# Windows Forms inventory-tracking exercise from my programming coursework at the University of Advancing Technology (UAT).

This project explores how a graphical interface can collect and manage information using form controls and C# data structures.

## Technical focus
- Working with Windows Forms and text input controls
- Using arrays and C# variables to represent data
- Connecting user actions to application behavior
- Practicing basic application organization and data validation concepts

The repository contains the coursework implementation. Features beyond those shown in the source code should not be assumed.

## Running the project
Use Visual Studio with the .NET desktop development workload. Open the included solution or project file, build the application, and run it through the debugger.

## Portfolio relevance
Supporting evidence of software development fundamentals and interface design. This is not evidence of enterprise inventory management or cloud scalability.
